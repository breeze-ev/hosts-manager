Open source macOS hosts manager

Hosts Manager

Manage `/etc/hosts` with profiles, live apply, source editing, and automatic backups.

View Source ↗ Releases ↗

Open-source releases use a free Apple Development identity. macOS may ask you to approve the app under Privacy & Security on first launch.

Built for daily hosts work

Profiles instead of manual edits

Keep separate hosts configurations, switch quickly, and see exactly what will be written before it happens.

Profile switching

Enable one profile or combine several enabled profiles into a single written result.

Combinable profiles

Enable several profiles at once and write their merged result in one step.

Import and export

Move profiles between machines with structured import and export.

Real-time apply

List edits apply immediately when a profile is enabled, with conflict detection first.

Source editing

Edit hosts text directly with comment and uncomment actions when you need full control.

Automatic backups

Every write is backed up first and can be previewed or restored later.

Native Swift

Built with Swift and SwiftUI for macOS.

Privileged writes, contained

No broad root access

The helper only accepts a signed Hosts Manager caller from the same signing team and performs one validated write operation.

Same-team helper

The background writer validates the caller's signature and bundle identifier before serving requests.

Atomic writes

Hosts content is validated and written atomically while preserving file permissions.

No telemetry

No analytics or tracking. Sparkle, the bundled open-source updater, contacts only the signed appcast and GitHub Releases for updates.

Local storage

Profiles and backups live in Application Support and are never uploaded.

Requirements

macOS 26+

Build with Xcode 26.6 or newer. The app and helper use the same signing team for development and distribution.
